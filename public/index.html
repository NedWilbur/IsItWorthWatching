    About

    Everything is better when nobody ruins it by telling you a movie or show will change your life. Skip the endless hype and use this tool to easily dodge duds and find something great to watch tonight.

    The algorithm behind this recommendation tool is the culmination of years of obsessive development. It's been fine-tuned, argued over, and blessed by an elite panel of film critics, compulsive mathematicians, eccentric magicians, and actual wizards (if (rating >= 60%) return 'Yes.'; else return 'No.';).

    This project is open source. Enjoying the website? Give back.

    Movie data and audience ratings are provided by The Movie Database (TMDB). This product uses the TMDB API but is not endorsed or certified by TMDB.
